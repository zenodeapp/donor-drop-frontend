## Installation

### 0. Setup backend

See: https://github.com/zenodeapp/donor-drop-backend

### 1. Install dependencies
```
npm install
```

OR

```
yarn install
```

### 2. .env configuration
Create an .env file in the root. See [.env.example](.env.example) for an example.

### 3. Run app (for development)

```
yarn dev
```

OR

```
npm run dev
```

### 4. Run app (for production)

```
yarn build
yarn start
```

OR

```
npm run build
npm run start
```
